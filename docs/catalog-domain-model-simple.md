# Термины в одной странице

Актуальная модель после разделения сервисов, 16.09.2026.

```text
Benchmark — группа
└── Test — одно испытание / карточка
    ├── инструкции, описание, примеры, внешние ссылки
    ├── DatasetSubsample[] — части для описания состава
    ├── UUID выбранных Metric — что измерять
    └── human baseline — ориентир результата человека

MetricResult = Test ID + Model ID + Metric ID + готовое число
CatalogEntry = Test ID + автор + решение о публикации
```

Benchmark Service владеет группой и описанием Test. Каталог владеет метриками, результатами, справочниками, модерацией, поиском и диалогами. Каталог хранит копию описания из Kafka, но не пишет в БД источника.

Test — не автотест проекта. DatasetSubsample — не самостоятельный Dataset. Рекомендация — не результат испытания. Ни Run, ни отдельной ModelVersion здесь пока нет.
